# Xeno — Crypto Assistant (MVP)

Учебный MVP для новичков в криптовалюте. Проект работает оффлайн, не подключается к кошелькам и не запрашивает секретные данные.

## Быстрый старт

### Установка

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

### Сборка

```bash
npm run build
```

### Запуск продакшн-сборки локально

```bash
npm run preview
```

### Тесты (Vitest)

```bash
npm run test
```

## Деплой на Vercel

1. Установите Vercel CLI (опционально):
   ```bash
   npm i -g vercel
   ```
2. Запустите деплой:
   ```bash
   vercel
   ```
3. Следуйте инструкциям в терминале. В проекте не требуется дополнительная настройка.

## Важные принципы безопасности

- Xeno не даёт инвестиционных советов.
- Мы не подключаем кошельки и не просим seed-фразы.
- Все модули работают локально в браузере.
